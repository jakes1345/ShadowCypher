// The platform

One account, four ways in.

The desktop app does the work that has to happen on your machine. The web app holds your account services. Both talk to the same API, which you can run yourself.

Linux · Qt6 · C++

Desktop app

A native app with a background daemon. Everything that touches your network runs locally.

  • Guardian: devices on your LAN and new-device incidents
  • Network scans with nmap, arp-scan and tcpdump
  • Threat intel: recent CVEs from NVD and a package audit
  • Counter-intel: ARP spoofing, DNS leaks, rogue DHCP, TLS interception
  • OSINT and vulnerability tools for targets you're authorized to test
  • AI assistant on a local Ollama model
  • Ghost mode: Tor with a kill-switch
Any browser

  • Guardian dashboard and push alerts
  • Shadow AI assistant

// Privacy

What we protect, and what we don't yet.

Security tools shouldn't oversell. Here is exactly where your data goes and what is encrypted today.

AreaStatusDetails
TelemetryNoneThe apps send no usage data. Syncing scan results to your account is off until you turn it on.
ChatEnd-to-endMessages are encrypted in your browser with AES-GCM while your chat vault is unlocked. The key stays in memory and never reaches the server.
PasswordSplitNew web accounts stretch the password with Argon2id on your device. The server gets a derived login secret; the other half unlocks your OpenPGP key, which only unlocks on your device.
MailNot end-to-end yetStored on the server as received. Mail between ShadowCypher users stays on the platform and never goes through an outside mail provider.
DriveNot end-to-end yetFiles are stored on the server as uploaded.
Self-hostingSupportedRun the API, database and storage yourself. Self-hosting guide
Desktop app

Ghost mode

Routes your traffic through Tor and adds an iptables kill-switch, so nothing goes out in the clear if Tor drops. It's the only part of the app that needs root, and it asks through your system's normal password prompt.

Tor is slower than a normal connection. It's built for anonymity, not streaming or gaming.

Desktop app

Counter-intel checks

Looks for the signs of someone interfering with your network: ARP spoofing, interfaces in promiscuous mode, DNS leaks, rogue DHCP servers, TLS interception and unusual traffic.

// ShadowOS · in development

A hardened Linux with ShadowCypher built in.

An Arch-based live ISO with Hyprland, the hardened kernel, nftables, AppArmor, Tor and dnscrypt-proxy. One command switches the firewall, Tor routing and services between modes. There's no download yet: you build the ISO yourself.

Modes

shadow-mode normal shadow-mode privacy shadow-mode ghost shadow-mode dev shadow-mode gaming

Build it

cd shadowos sudo bash build.sh # Arch host bash build-docker.sh # any host with Docker bash qemu-test.sh # boot it in QEMU ShadowOS on GitHub →
// Download

Get ShadowCypher.

The web app needs nothing installed. The desktop app is built from source; there's no packaged release yet.

Linux desktop · v1.0

Desktop app

Needs CMake, Ninja, a C++17 compiler, OpenSSL and Qt 6.4 or newer.

git clone https://github.com/jakes1345/ShadowCypher cd ShadowCypher cmake -S shadowcypher-qt -B build -G Ninja cmake --build build

Sign in from the app: it opens your browser to approve the device.
