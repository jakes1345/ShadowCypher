# ShadowOS Security Advisories

## Latest Advisories

### CVE Scanning

ShadowOS performs automated CVE scanning on all released packages.

## Reporting Security Issues

Please report security vulnerabilities responsibly:

**Email:** security@shadowcypher.site

Include:
- Description of vulnerability
- Affected versions
- Proof of concept (if possible)
- Your suggested fix (if any)

We will:
1. Confirm receipt within 24 hours
2. Provide estimated fix timeline
3. Credit you in the security advisory

## Security Updates

Security updates are released as needed. Check for updates:

```bash
sudo shadowos-update check
```

## Supported Versions

- **ShadowOS 3.0.x** - Actively supported (security + feature updates)
- **ShadowOS 2.2.x** - Security updates only (until 2026-12-01)
- **ShadowOS < 2.2** - End of life
