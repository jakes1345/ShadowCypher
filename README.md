## ⚡ SETUP & DEPLOYMENT

### 🏗️ PREREQUISITES
ShadowCypher requires a modern Linux environment with the following dependencies:
- **Python 3.10+**
- **PyGObject (gi)**: GTK3 / GDK / PangoCairo
- **libcairo2-dev**
- **Ollama**: For local AI Swarm execution (`ollama run llama3`)
- **System Utils**: `psutil`, `requests`, `python-dotenv`

### 🛠️ INSTALLATION
```bash
# 1. Clone the Dossier
git clone https://github.com/jack/ShadowCypher.git
cd ShadowCypher

# 2. Install Python Core
pip3 install -r requirements.txt

# 3. Initialize AI Backend
ollama serve  # Run in a separate terminal
```

### 🚀 EXECUTION
To launch the ShadowCypher Command Center:
```bash
python3 -m shadowcypher.app
```
